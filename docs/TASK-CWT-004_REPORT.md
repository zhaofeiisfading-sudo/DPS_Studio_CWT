## 🔬 方法、冻结与输入合同

预注册协议为[PROTOCOL](TASK-CWT-004_PROTOCOL.md)，实施测试修正记录为[IMPLEMENTATION_NOTES](TASK-CWT-004_IMPLEMENTATION_NOTES.md)。正式开始前已冻结协议、源码、配置、种子与评价区域；正式实验期间已快照文件哈希全部保持一致。首轮开发失败没有隐藏，原始日志在TASK004产物根下development_*。没有正式后调参或协议修订，没有修改src正式算法、TASK003映射或任何旧结果。

CWT：cmor1.5-1.0，PyWavelets FFT，precision18，0.1–6GHz，24 voices/octave含精确高端点，共143尺度；raw abs(W)，逐样点argmax。Balanced：periodic Hann 768/640/128/4096；High time：512/384/128/4096，依次为window/overlap/hop/NFFT。STFT由SciPy ShortTimeFFT独立实现，频带内逐帧strongest，无精修、删点或后处理。两种库的单位/中心约定由官方文档与安装版本源码核对[^1][^2]，另以直接FFT数值验证。

STFT窗口为[c−L/2,c+L/2)，c=128p；只输出中心在真实记录内的帧，超出窗口补零且标风险。没有减均值或滤波。正频幅值为2 abs(FFT)/sum(Hann)，单位V，作为实正弦峰幅估计；不含DC或Nyquist。CWT为离散样点尺度约定的系数幅值V，随尺度有增益差异，不能与STFT raw幅值共用未经校准色标。实际STFT频率格点在40GS/s为0.107421875–5.99609375GHz，80GS/s为0.1171875–5.99609375GHz，均是同一0.1–6GHz约束内的合法格点。

### 背景暗色与E(t)存在性设想

所有方法保存E=max response、频带median/q90、peak/median及平方谱集中度；不同频网格的集中度不能视为等价的连续概率密度。真实数据没有独立可靠背景标签，噪声标准化一律NOT AVAILABLE；dB图仅用各方法共同内部“时间median(频带median)”作record reference，统一20log10(response/reference)、−20..60dB，是定性记录参考，非SNR或噪声标定。

线性色标vmin0、vmax取各方法完整矩阵最大值。低于该vmax的1%的网格单元比例：CWT为12.283%–95.031%，Balanced为31.015%–97.716%，High time为47.809%–96.703%。20260607第二通道分别80.353%、95.803%、93.979%；暗背景并非CWT独有优势。这些是不同频网格的单元比例，不是背景物理面积、无信号概率或真实误报率。

模型解释：动态范围、CWT尺度增益和色标上限都会压暗弱响应；背景接近色标底部不等于所有频率响应为零。E(t)可以作为需要校准的存在性诊断，合成结果支持部分条件下的可分性，但低响应也可能来自弱信号、频段外能量或相消；本任务没有把候选删掉、速度置0或改写旧CSV。真实无标签时，E低只能描述为“该分析频带支持较弱”。
