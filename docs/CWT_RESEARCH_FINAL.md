## 研究问题与物理解释范围

PDV 电压信号可在局部单分量近似下表示为 $x(t)=A(t)\cos\phi(t)+n(t)$，其拍频为 $f_b(t)=\dot\phi(t)/(2\pi)$。本研究考察复 Morlet 连续小波变换在频率变化和弱信号条件下的 strongest 候选提取表现，与两组固定 Hann-STFT 对照。幅度变化、多分量叠加、暂时衰落和背景噪声均可能使最大谱响应偏离预先指定目标。因此，可见时频带、最大响应候选和真实运动支路属于不同层次的证据。

在显式零光学偏置、给定真空波长及相应反射多普勒模型下，软件只提供无符号表观速度 $v_{\mathrm{app}}=\lambda_0 f_b/2$。本项目真实数据的波长、参考光学偏置、观测角度、窗口条件和独立速度真值尚不完整，未输出经物理验证的速度。不得将合成条件下的频率误差改称真实实验速度误差。后续角度或窗口修正不属于本研究实现。

## 方法与数学合同

连续时间定义采用

$$W_x(a_t,b_t)=\frac{1}{\sqrt{a_t}}\int x(t)\psi^*\!\left(\frac{t-b_t}{a_t}\right)\,dt,$$

其中 $a_t$ 以秒计。计算使用 PyWavelets 的样点尺度 $a=a_t/\Delta t$，与样点尺度位移相应定义的离散系数记为 $W[a,n]$；其数值约定不含采样间隔因子，物理时间系数对应乘 $\sqrt{\Delta t}$。本研究的响应单位遵循离散约定，未把两种幅值混用。母小波为 $\psi(u)=(\pi B)^{-1/2}\exp(-u^2/B)\exp(i2\pi Cu)$，固定 $B=1.5,C=1$。尺度映射实际采用库的 `frequency2scale` 和 `scale2frequency/Δt` 往返核验，不能仅用名义中心频率代替离散标定。[PyWavelets 官方定义与尺度说明](https://pywavelets.readthedocs.io/en/latest/ref/cwt.html)支持这些 API 和单位约定。

全记录采用 FFT 卷积、precision=18、0.1—6 GHz，24 voices/octave 时为143尺度；48和96 voices分别为285和569尺度。输入时间为秒、电压为伏，非均匀采样直接拒绝。输入不经平滑、插值、重采样或异常点删除；每个原始时刻保留一个候选。质量与边界标志独立保存，不修改候选。全库边界半径为 $\max_a(\lceil8a\rceil+2)$ 样点，这是一项保守的有限支撑风险标记。频带低于 Nyquist 之外，还检查连续小波谱越界尾能量，并以实际离散滤波核审计补充；通过该检查并不证明没有任何离散伪影。

| 方法 | strongest 评分 | 校准或窗口 |
| --- | --- | --- |
| A0（默认） | $|W[a,n]|$ | 保留原始尺度增益 |
| A1（实验） | $|W[a,n]|/\sqrt a$ | 去除主要单频尺度幅值偏好 |
| A2（实验） | $|W[a,n]|/r_a$ | 独立1 V RMS合成噪声的系数RMS，按采样率、PSD及网格分组 |
| Balanced STFT | 带内单边幅值最大值 | periodic Hann，L768、hop128、NFFT4096 |
| High time STFT | 同上 | periodic Hann，L512、hop128、NFFT4096 |

A2 相对于独立参考噪声作二阶响应标准化，不是信号幅值校正或显著性概率。同一波形、同一频网格下三种 CWT 评分共用一次完整系数矩阵。默认 A0 保持不变；A1和A2均不引入目标识别或连续性约束。

STFT 各窗口按实际样点中心 $c=128p$ 定义，越界补零并标记；单边正频幅值为 $2|\mathrm{FFT}(xw)|/\sum w$，未减均值。窗口、hop、FFT网格及幅值缩放由安装实现和直接FFT测试共同核验，[SciPy ShortTimeFFT 官方说明](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.ShortTimeFFT.html)给出对应 API 约定。40 GS/s下两窗口为19.2/12.8 ns，80 GS/s下为9.6/6.4 ns；FFT格点间隔分别9.765625/19.53125 MHz。Hann首零点间宽度为 $4f_s/L$，与FFT格点间隔不是同一量。CWT逐样点输出和STFT逐帧输出的密度差异也不能替代真实时间分辨能力实验。

## 稳定频率与尺度响应偏差

局部单频、连续尺度及忽略负频尾的近似给出 $|W|\simeq A\sqrt a\exp[-\pi^2B(af\Delta t-C)^2]/2$。最大化该表达式时，$q=af\Delta t$ 满足 $q(q-C)=1/(4\pi^2B)$，故A0选择频率约为真频的0.983660倍。此为理论机制近似，不是针对所有离散核和噪声条件的误差修正公式。A1消去 $\sqrt a$ 后理想单频峰回到真频附近，剩余误差仍含网格量化和实际离散滤波响应。

无噪1 GHz的历史实测内部bias为A0 −20.757 MHz、A1 +7.937 MHz。40 GS/s的12个无噪off-grid恒频，A0在24/48/96 voices的合并RMSE为55.269/34.325/41.494 MHz，A1为18.430/9.615/6.460 MHz；对应A0 bias为−37.454/−26.295/−29.785 MHz，A1为+13.727/−0.403/−1.067 MHz。A1密化改善量化误差，A0却保留偏差并出现非单调结果。0 dB恒频时A1在40 GS/s的误差为93.981/90.466/95.662 MHz，进一步密化没有稳定降低噪声选择错误。

## 多分量、检测与真实数据

必须区分匹配真频邻域内是否存在局部峰、峰的响应排序、Top-K命中与最终strongest选择。白噪声高频−10 dB时，A0真频局部峰presence在40/80 GS/s约为57.99%/67.77%，达到预定peak/median支持条件的比例仅26.30%/45.42%。有些错误来自峰缺失，有些来自峰存在而未被选择；任意小峰也可能来自噪声。双分量弱目标2 GHz、强干扰0.5 GHz时，所有方法的目标局部峰presence和Top3 recall均100%，wrong-branch仍为100%。这直接否定“Top-K出现即恢复运动支路”的解释。目标交换至低频时A0相对较好，但错误率仍高且依赖评分，不能宣称已解决多支路识别。

TASK005检测阈值用独立60条噪声记录校准，名义逐帧1%和逐记录5%。held-out中80 GS/s有色噪声的Balanced逐记录误报7/40，Wilson95%区间约8.75%—31.95%；0/40的条件上界仍约8.76%。实际误报约束没有严格一致，起跳方法的胜负不能被表述为已在相同实测误报率下验证。40 GS/s、5 GHz、4 ns脉冲的A2漏检45%，必须与起跳误差同时报告。

真实结果涵盖10个文件、14个映射电压通道，共1,240,002个native样点。TASK006复核全部保存时间、候选、通道映射和原始字节哈希关联；真实波形未重新解析或重新变换。TASK003为14/14 SCALOGRAM_ONLY；TASK004三方法及TASK005三评分输出均保留。真实noise、quality与truth均UNKNOWN，A2只使用synthetic-white参考并标记探索性。A1相对A0共同内部候选修改45.420%—81.707%，A2修改4.878%—14.484%；这些是修改率，不能称纠错率。
